To Enable Real Google Accounts:

  1. Visit the Google Cloud Console → APIs & Services → Credentials.
  2. Create an OAuth 2.0 Client ID (Web application).
  3. Set Authorized redirect URIs to: http://localhost:8000/auth/google/callback/
  4. Add the keys to your .env file:
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com GOOGLE_CLIENT_SECRET=your-client-secret
